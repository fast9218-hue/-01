# 안전보건 교육 사진 엑셀 자동생성 & 메일 발송 안드로이드 앱

업로드하신 `업로드 양식.xlsx` 양식에 맞춰 **카메라 촬영 / 갤러리 선택 → 순서 정렬(사진 1, 사진 2, 사진 3...) → 엑셀 표 자동 삽입 → 메일 자동 발송**을 수행하는 안드로이드(Kotlin + Jetpack Compose) 프로젝트입니다.

## 주요 기능
1. **카메라 촬영 & 갤러리 다중 선택**: 찍은 사진은 EXIF 회전값을 자동 보정하여 세로 사진도 눕지 않고 정방향으로 들어갑니다.
2. **순서 정렬 (사진 1, 사진 2, 사진 3...)**: 위/아래 버튼으로 순서를 바꾸면 `내용` 문구(`1-1`, `1-2`, `1-3`...)도 함께 맞춰집니다.
3. **엑셀 표 맞춤 삽입**: `app/src/main/assets/업로드 양식.xlsx`를 기반으로 비율을 유지한 채 셀 중앙에 여백을 두고 깔끔하게 삽입합니다. 3장 이상일 경우 동일한 서식의 `사진 3`, `사진 4` 블록을 자동으로 이어 붙입니다.
4. **이메일 자동 발송 (SMTP) & 공유**: 우측 상단 톱니바퀴에서 보내는 메일(Gmail/Naver 앱 비밀번호)과 받는 메일(PC 확인용)을 등록해 두면 버튼 한 번으로 자동 발송됩니다.

## APK 빌드 및 설치 방법
1. 이 압축 파일을 풀고 **Android Studio**에서 `SafetyPhotoExcelApp` 폴더를 엽니다.
2. Gradle 동기화 완료 후 상단 메뉴 **Build > Build Bundle(s) / APK(s) > Build APK(s)**를 클릭합니다.
3. 생성된 `app-debug.apk`를 스마트폰(Galaxy Z Fold 8 등)으로 옮겨 설치하거나, USB 디버깅 연결 후 바로 **Run**으로 설치합니다.
